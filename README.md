## Publications

### A Zero-Trust Middleware Architecture for Securing Agentic Workflows against Tool Poisoning
IEEE E-Summit, March 2026

Identified and demonstrated eight novel metadata-based attack vectors — termed Adversarial Metadata Injection — within the Model Context Protocol (MCP) ecosystem. Proposed and implemented MCP Sentinel Gateway, a zero-trust middleware layer that sanitizes tool metadata before it reaches an LLM, preventing instruction hijacking and unauthorized data exfiltration in agentic tool-use pipelines.

[Read the paper](https://www.ijsrmes.com/archives/volume-7/special-issue) (Paper ID: IJSRMES2026S08)

### Agentic Multipurpose Research Engine with RAG and Tool Orchestration
An AI system designed to go beyond conversational chat by combining an LLM with Retrieval-Augmented Generation, persistent memory, and multi-tool orchestration to automate research workflows — addressing the fragmented, manual, and time-intensive nature of traditional research processes.

Architecture:
- **RAG pipeline** — documents are loaded, chunked, and embedded into a vector store; the most relevant chunks are retrieved via semantic search and passed to the LLM alongside the user's query as context.
- **Multi-agent orchestration via MCP** — a host client coordinates multiple MCP servers (including a Manim server for generating mathematical animations, plus arithmetic and logic tool servers) exposing tools, resources, and prompts to the LLM.
- **Reasoning and memory** — Gemini LLM handles advanced reasoning, with conversation history maintained for context-aware, multi-turn responses.

Future scope identified: voice-based interaction, real-time web data integration, graph-based memory (Neo4j), fully autonomous agents, and multimodal (image/video) support.
[manim-mcp-server](https://github.com/STIWARTs/manim-mcp-server) · [remote_expense_tracker_mcp_server](https://github.com/STIWARTs/remote_expense_tracker_mcp_server) · [MultiagentSystem](https://github.com/STIWARTs/MultiagentSystem) · [mcp-client](https://github.com/STIWARTs/mcp-client)
